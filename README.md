## Personal Financial Tracker (Python Capstone Project)
This is a code demonstration of a personal finance tracker using Python.
The User can add expense, view all the expense, and check a summary of the spending.

## Project objectives
Apply core Python programming concepts to build a simple command line that can reinforce understanding of variables, data types, control structures, loops, functions, string operations, lists, dictionaries, tuples, and exception handling.

## Features
- Add expense with description, category and amount.
- View all expenses by category and description.
- View a summary with total spending by category.
- The main function uses user input to choose an option.

## How to Run
1. Clone the repository or download the code.
2. Use Terminal and open the project folder.
3. Run the script using Python.
